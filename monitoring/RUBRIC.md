# 留言分類 Rubric（一日 vs 兩日議題）

> 所有分類 run（人手或 agent）必須跟呢份。改 tag 定義要同步改呢度＋重跑受影響批次。

## Tier 證據分級（判「發言人」，唔係判「留言」）

| Tier | 定義 | 例 |
|---|---|---|
| R1 實錘跑手 | 第一身參賽證據 | 自己抽籤/報名/完賽/PB/配速/操練/拎跑手包/「啱啱跑完柏林」 |
| R2 疑似跑手 | 賽事結構知識 | 出發間距/金標白金/賽道重疊/封路時數/海外賽制細節/挑戰組 |
| S 唔跑抽水 | 零跑步訊號 | 純封路擾民/搞笑/鬧議員鬧政府/湊熱鬧 |
| U 判唔到 | 證據不足 | 單字/emoji/純轉貼新聞/離題 |

- **Speaker-based**：同一人喺同一 thread 其他留言有跑步證據，佢全部留言跟人升級
- 陷阱：「支持但我跑唔到」≠跑手；引新聞=U；純鬧霍啟剛/議員/政府=S
- 常識性知識（「渣馬朝早跑」）唔算結構知識，唔升 R2

## Stance（對分兩日）

support / oppose / mixed / neutral / na

- **反串警覺**：誇張讚美+😆／「不如分365日」係反串，唔可以照字面判 support。判唔實→mixed 並註明
- 護航渣馬鬧第三方但冇講分日 → **na**（唔好硬塞入 support）
- 有條件支持（「ok 但唔可以冧金標」）→ mixed

## Argument tags

### 支持側
`半馬樽頸加唔到位` `10K拆走封路唔加` `出發間距到極限` `海外分兩日先例`（限：真係引外國分兩日——GoldCoast/新加坡/KL/台北）`帶動經濟` `分散人流安全` `全馬跑手可join短途當shake out` `半全馬賽道重疊` `封路影響有限` `與眾同樂日借鏡紅酒馬`

### 反對側
`拆10K幫唔到半全馬` `星期六要返工` `義工醫療double` `唔信田總執行` `氣氛分薄` `封路擾民` `封路時數` `商業化搵錢` `凌晨起步` `分法唔可行` `另設新賽事好過` `已有同類賽事` `中籤率已高` `名額不公`
`連一日都未搞好（海外對照）`——引外國全日封路/正常時間起步對照香港偷雞開跑早解封（**唔係**海外先例！）
`名馬都限額唔遷就人多`——東京大阪唔會因人多加日
`金標唔可以冧` `已分起點分流唔使分日` `為搞而搞唔如做好本業` `新加坡分完反而封頂`

### 中性/其他
`賽道路線` `名額不公` `金標係前提` `純情緒` `無論點` `反串難辨`

## ⚠ 一詞多義教訓（2026-08-10 用戶QC）

「海外先例」曾經一個 tag 揹晒四種意思：
1. 外國**分兩日**先例（真・支持論點）→ `海外分兩日先例`
2. 外國**全日封路**對照香港縮骨 → `連一日都未搞好（海外對照）`（反對論點！）
3. 外國名馬**有限額唔遷就** → `名馬都限額唔遷就人多`（反對論點）
4. 紅酒馬**嘉年華文化** → `與眾同樂日借鏡紅酒馬`

判 tag 時問自己：**個海外例子係度支持緊乜？** 唔係見到外國賽事名就掟入「海外先例」。

## 流程

1. 分類 agent 跑（batch，寫 JSON 檔）
2. 嚴格 audit pass 複核全部 R1/R2（捉假陽性）
3. 人手抽查 deck 頁——發現錯 tag 就補入呢份 rubric 嘅陷阱清單
